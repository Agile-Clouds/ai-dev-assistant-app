# Report a security problem

Please email [support@agile-clouds.com](mailto:support@agile-clouds.com).

Say what happened, what you expected and the shortest safe steps that show the problem. Say which AI Dev Assistant version and computer system you used.

Do not open a public issue for a security problem. Do not paste keys, tokens, passwords, `.env` contents, private code, private links or personal data into an issue or email. Remove secrets from pictures and logs before you send them.

The team will reply by email.
